Your privacy matters

This demo keeps the information you type in page memory only.

It does not create an account, store entries in a database, upload them, or create a public profile or share link. CV answers stay available while this page is open so you can tailor more than one draft; refreshing or closing this page clears them.

Skill suggestions and CV tailoring use local keyword rules, not an AI service.

A production service would need secure accounts, consent-based sharing, revocable links, referee workflows and reviewed privacy controls. Those are proposed features, not part of this demo.
